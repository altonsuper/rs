# Script WhatsApp — KamarPasti (agen resmi RedSeller RedDoorz)

Cara pakai: simpan sebagai **Quick Reply** di WhatsApp Business (Settings → Business tools → Quick replies).
Ketik `/kode` lalu kirim. Ganti `{...}` sebelum kirim.

Aturan yang bikin kamu dipercaya:
- Balas pertama **< 10 menit** di jam operasional. Kecepatan = satu-satunya keunggulan yang tidak bisa dibeli aplikasi.
- **Jangan pernah** bilang "pasti ada kamar" sebelum kamu cek di aplikasi RedSeller.
- Selalu tulis **total**, bukan harga per malam saja. Orang takut biaya tersembunyi.
- Satu orang, satu nomor, dari tanya sampai check-in. Jangan oper-oper.

---

## 0. Setup WhatsApp Business (30 menit, sekali saja)

| Fitur | Isi |
|---|---|
| Nama profil | KamarPasti — Agen Resmi RedDoorz |
| Kategori | Travel & Transportation |
| Deskripsi | Agen resmi program RedSeller RedDoorz. Menginap mingguan/bulanan, keluarga pasien, rombongan kerja. Balas < 10 menit (07.00–22.00). |
| Jam kerja | 07.00–22.00 (tulis jujur, jangan 24 jam kalau kamu tidur) |
| Greeting | `/salam` |
| Away message | `/away` |
| Label | `1-Baru` `2-Dikirim Pilihan` `3-Booking` `4-Menginap` `5-Selesai` `6-Repeat` `Alert` `Partner` |
| Katalog | 4–8 properti yang sudah kamu cek. Foto asli + jarak jalan kaki + harga kisaran. |

**Label = CRM gratis.** Setiap chat wajib punya satu label. Kalau tidak dilabel, kamu akan kehilangan uang di chat yang lupa dibalas.

## 1. `/salam` — balasan pertama (semua pertanyaan)

```
Halo {nama}, saya {kamu} dari KamarPasti, agen resmi RedSeller RedDoorz 🙏

Biar saya carikan yang paling pas, boleh info:
1. Dekat mana? (rumah sakit / kampus / stasiun / alamat)
2. Mulai tanggal berapa, berapa malam?
3. Berapa kamar?
4. Budget per kamar per malam?

Saya balas dengan 2–3 pilihan lengkap foto + total biaya, maks 15 menit.
```

## 2. `/away` — di luar jam kerja

```
Halo! Pesan kamu sudah masuk ✅
Saya online lagi jam 07.00 dan akan balas paling pertama.

Kalau butuh kamar untuk malam ini juga, tulis: URGENT — saya usahakan cek dari HP.
```

## 3. `/pilih` — kirim pilihan (ini yang menutup penjualan)

```
Ini 3 pilihan terdekat dari {patokan}, {tanggal}, {n} malam, {k} kamar:

1) {properti} — {jarak} jalan kaki
   {harga}/malam × {n} malam × {k} kamar = *{total}*
   ✅ {kelebihan}  ⚠️ {kekurangan jujur}

2) {properti} — {jarak}
   *{total}* — ✅ {kelebihan} ⚠️ {kekurangan}

3) {properti} — {jarak}
   *{total}* — ✅ {kelebihan} ⚠️ {kekurangan}

Harga sudah termasuk pajak, tidak ada biaya tambahan dari kami.
Mau saya kunci yang nomor berapa? Saya cek ketersediaan ulang dulu sebelum booking.
```

> Kolom ⚠️ wajib diisi. "Kamar tanpa jendela", "AC kurang dingin", "tangga, tidak ada lift".
> Jujur di depan = tidak ada komplain di belakang = tamu repeat. Ini strategi, bukan kebaikan hati.

## 4. `/objection` — "kenapa nggak booking sendiri di aplikasi?"

```
Boleh banget, harganya sama — saya tidak menaikkan harga 🙂

Bedanya kalau lewat saya:
• Saya yang cek ketersediaan & jarak asli, kamu tidak perlu buka 10 listing
• Kalau kamar ditolak resepsionis, kamu chat saya, saya urus — bukan call center
• Menginap lama/rombongan: saya carikan tarif mingguan/bulanan + rekap biaya untuk kantor
• H-1 saya kirim alamat, pin lokasi, aturan check-in

Kalau kamu lebih nyaman booking sendiri, tetap saya bantu carikan yang terbaik. Nomor saya simpan saja.
```

## 5. `/confirm` — setelah booking berhasil

```

Kamar: {k} · {n} malam
Total: *{total}* — dibayar {metode}
Atas nama: {nama tamu}

Tunjukkan kode ini + KTP di resepsionis.
Alamat & pin lokasi: {link}
Nomor properti: {telp}

Saya kabari lagi H-1. Kalau ada apa pun di lokasi, chat saya di nomor ini, jangan diam saja 🙏
```

## 6. `/h1` — pengingat H-1 (paling menaikkan rating kamu)

```
Halo {nama}, besok check-in di {properti} ya 👋

📍 {alamat} — pin: {link}
🕑 Check-in mulai {jam}
🔑 Bawa: kode booking *{kode}* + KTP semua tamu
ℹ️ Catatan: {aturan penting: deposit / jam malam / tanpa jendela / parkir}
📞 Resepsi: {telp}

Kalau sampai lokasi kamar tidak sesuai, langsung chat saya. Saya bantu sampai beres.
```

## 7. `/recover` — kalau kamar ditolak / tidak sesuai (momen penentu trust)

```
Maaf ya {nama}, ini tanggung jawab saya 🙏
Jangan pindah dulu / jangan bayar apa pun ke pihak lain.

Saya lakukan sekarang:
1. Hubungi properti untuk pastikan masalahnya
2. Kalau memang tidak bisa: saya carikan pengganti setara atau lebih baik, selisih harga saya tanggung
3. Kalau kamu pilih batal: saya bantu proses refund penuh sesuai ketentuan

Saya update ke kamu dalam 15 menit, ada kabar atau belum ada kabar.
```

> Anggaran "goodwill" kecil (mis. Rp 50rb/bulan) untuk menutup selisih itu **lebih murah daripada iklan**,
> dan satu cerita penyelamatan yang diceritakan tamu = 5 tamu baru.

## 8. `/longstay` — keluarga pasien (niche paling menguntungkan)

```
Bu/Pak, untuk pendamping pasien biasanya butuh 1–4 minggu, dan tarif menginap lama lebih hemat daripada bayar harian.

Yang biasa saya bantu:
• Kamar jalan kaki ke {RS} — jadi bisa bolak-balik tanpa parkir
• Tarif mingguan/bulanan (saya cekkan yang paling hemat)
• Bisa tambah malam mendadak, tidak perlu cari ulang
• Rekap biaya kalau perlu untuk keluarga/kantor

Rencana berapa lama, dan mulai tanggal berapa? Saya kirim 2 pilihan terdekat.
```

## 9. `/crew` — rombongan / HR / kontraktor (order paling gemuk)

```
Selamat pagi Pak/Bu {nama}, saya {kamu} dari KamarPasti, mitra reseller resmi RedDoorz.

Kami biasa bantu penginapan tim proyek / karyawan baru di {kota}:
• {k} kamar untuk {n} malam, satu kode booking, satu penanggung jawab
• Tarif menginap lama (lebih hemat dari harian)
• Rekap biaya + invoice bulanan untuk finance
• Ganti/tambah kamar di tengah jalan cukup chat saya

Kalau ada jadwal mobilisasi tim, boleh saya kirim penawaran? Cukup info: kota, jumlah orang, tanggal, budget per kamar.
```

## 10. `/follow` — belum dibalas (maks 2×, lalu berhenti)

```
Halo {nama}, kamar yang {properti} masih ada untuk {tanggal}.
Mau saya tahan dulu atau kamu masih bandingkan? Dua-duanya tidak masalah 🙂
Kalau sudah dapat tempat lain, cukup balas "sudah" — saya berhenti mengganggu.
```

## 11. `/review` — setelah check-out (mesin repeat + bukti sosial)

```
Halo {nama}, terima kasih sudah menginap lewat KamarPasti 🙏
Boleh minta 1 kalimat: kamarnya sesuai tidak dengan yang saya jelaskan?

Kalau ada yang kurang, tolong bilang jujur — saya perbaiki catatan properti itu.
Kalau puas, boleh saya tampilkan chat ini (nama disamarkan) sebagai testimoni?

Nanti kalau butuh kamar lagi di {kota}, cukup chat "seperti kemarin" — data kamu sudah saya simpan.
```

## 12. `/rebook` — order ke-2 (hampir tanpa effort)

```
Siap {nama}! Seperti sebelumnya ya:
{properti} · {k} kamar · {n} malam · mulai {tanggal}
Perkiraan total {total}.

Saya cek ketersediaan sekarang, 10 menit saya kabari. Ada yang diubah?
```

## 13. `/alert` — broadcast mingguan ke daftar Alert

```
INFO KAMAR MURAH — {patokan} ({tanggal})

{properti} — {harga}/malam, {jarak} jalan kaki
{properti} — {harga}/malam, {jarak}

Butuh tanggal berapa? Balas: TANGGAL + JUMLAH MALAM.
Saya kirim yang cocok saja, tidak setiap hari.

Berhenti? Balas STOP — langsung saya hapus dari daftar.
```

> Kirim **maks 1× seminggu**, hanya ke orang yang lokasinya cocok. Sekali spam, daftar ini mati.

## 14. `/partner` — rekrut pengirim tamu

```
Halo Pak/Bu {nama}, saya {kamu} dari KamarPasti, agen resmi RedSeller RedDoorz.

Kalau ada {tamu kos / keluarga pasien / tamu grup} yang butuh kamar, cukup kirim ke saya:
nama, tanggal, berapa malam, budget. Saya yang cek, booking, dan tangani komplain.

Bagi hasil: {30}% dari komisi yang saya terima, dibayar tiap 2 minggu setelah komisi masuk.
Bapak/Ibu dapat link khusus: {link}?src={KODE} — semua tamu dari link itu tercatat otomatis.
Rekap bisa dicek kapan saja, saya kirim transparan.

Mau coba 1 tamu dulu untuk lihat cara kerjanya?
```

```
Komisi kotor: {Rp} · Bagian Bapak/Ibu ({p}%): *{Rp}*
```

```
Yang bisa saya lakukan: carikan properti lain yang memang lebih murah, atau geser tanggal kalau fleksibel.

```
